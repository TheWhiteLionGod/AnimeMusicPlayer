# Anime Music Player

An anime music player that's incredibly effective

## Installation

Use the UV package manager to install and run.

First clone repo:
```bash
git clone git@github.com:TheWhiteLionGod/AnimeMusicPlayer
```
or with https:
```bash
git clone https://www.github.com/TheWhiteLionGod/AnimeMusicPlayer
```

Then run:
```bash
uv run main.py
```

## Usage

Add a .env file with the following details:
```
ANILIST_USER={YOUR USERNAME HERE}
```

Then run the main.py file to start listening to music.
